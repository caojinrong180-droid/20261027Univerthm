# 故事板制作器（`web/storyboard.html`）

给**已经做好的谱面**做演出包装：导入谱面（**只读**）→ 用**场景**把演出串起来
（解锁动画 → 谱面 → 片尾）→ 存工程、导出整包、截图、录屏。

双击 `web/storyboard.html` 就能用（Chrome / Edge），没有构建步骤、没有依赖。
没谱面也想先看效果：点左边「**载入示例**」，或者打开 `storyboard.html?demo=1`。

> 这是「做画面」的工具，不是「做谱」的工具。要改谱面回 [`index.html`](index.html)（制谱器）。

---

## 1. 核心概念：故事板 = 一串场景

**解锁动画不在谱面里，它是谱面之前的一场。** 谱面场才开始画音符、才开始放音乐。

| 场景类型 | 干什么 | 时长 |
| --- | --- | --- |
| **解锁场** `unlock` | 谱面之前的演出：解锁动画 / 标题卡 / 倒计时 | 自己定（默认 2.6 秒） |
| **谱面场** `chart` | 真正放谱面（只读），音乐从这里开始 | **跟随谱面时长**，只读 |
| **演出场** `free` | 片尾 / 结算 / 过场 | 自己定（默认 3 秒） |

```
┌────────────┐ ┌──────────────────────────────┐ ┌────────────┐
│ 解锁演出     │→│ 谱面                          │→│ 片尾        │
│ 0 → 2.6s   │ │ 2.6 → 30.8s（= 谱面 28.2s）    │ │ 30.8 → 34.4s│
│ 磁带插入     │ │ 轨道 / 音符 / 打击画面          │ │ HARD LEVEL 8│
└────────────┘ └──────────────────────────────┘ └────────────┘
                  ↑ 音乐从这里开始
```

- 场景**顺序可调**（▲▼），可以没有谱面场（那就只是个纯演出），也可以来回切
- 每个场景**有自己的图层和后处理**，互不影响（解锁场的故障闪不会漏到谱面场）
- 图层时间用的是**场景内本地时间**（0 → 场景时长），挪场景不会打乱图层
- 总时长 = 所有场景时长之和；播放/录制/时间轴都按这个走

## 2. 谱面是只读的（硬约定）

| 事情 | 怎么做 |
| --- | --- |
| 读谱面 | 导入 `.json` / `.zip`，内部只调 `RChart.normalize()`，容错规则照 [CHART_FORMAT.md](../docs/CHART_FORMAT.md) §10 |
| 画谱面 | 只在**谱面场**里画，每帧按 [GAME_INTEGRATION.md](../docs/GAME_INTEGRATION.md) §2 的公式现算（`judgeY = H×0.85`、`cx = W/2 + x`、`d = Δt × basePps × speed²/100`…），只读不写 |
| 存工程 | 只存**谱面引用**：`{ file, title, artist, difficulty, level, notes, duration, bpm, lanes, hash }`，没有谱面内容 |
| 导出整包 | 把导入时那份 `chart.json` 的**原始字节**直接复制进 zip，不重新序列化 |
| 改谱面 | 这个工具里**没有**任何入口 |

工程里的 `hash` 是谱面文本的 FNV-1a 指纹（8 位十六进制）。重新打开工程时如果导入的谱面指纹对不上，
会提示「演出可能对不上」——不拒绝打开。

舞台上的「**谱面透明度 / 可视秒数**」是**故事板的显示设置**（相当于关卡的相机参数），
不是谱面内容，改它不会写进谱面。

## 2.5 谱面画面 = 游戏的 `stage_view.gd`（逐条对齐）

故事板的谱面层**不是**自己瞎画的：`web/js/chart_stage.js` 是 Godot `game/src/game/stage_view.gd` 的
JS 移植，两边常量、公式、剔除规则一一对应，所以同谱面同帧的画面逐像素一致（拿《Ж》实测对过）。

| 项 | 值 | 说明 |
| --- | --- | --- |
| 逻辑舞台 | `350 × 196.875` | 谱面的 x/y 就是按这个尺寸定的；故事板整体 ×(1280/350) 放大到 1280×720 |
| 判定线高度 | `round(196.875*0.85) = 167` | 不是按 720 算，所以构图和游戏一样 |
| 轨道宽度 | `min(350*0.05, 350*0.43/N) × 1.75` | 4 轨 30.6 → 16 轨 16.5 |
| 音符 | 半宽 `halfW-1`，半厚 `2`，圆角 `2.4` | 圆角矩形，不再是方块 |
| 判定线 | 宽 `halfW*2`、厚 `halfW*0.36` 的圆角实心条 | 跟着轨道一起转 |
| 轨道本体 | 只有两侧 1px 描边（`alpha*0.16`），**没有填充** | 游戏就是这样 |
| 长条 | 头实心、尾端渐隐（`fade = clamp(h*0.45, 5, 34)`），贴线时自带圆角帽 | 被轨道截断时不渐变 |
| 剔除 | 普通音符过线即消失；长条尾过线 -10 才消失；回看 `max(最长春条×最大流速, 4)` 秒 | 和游戏同一套 |
| 多押 | 同一时刻 ±20ms ≥2 个可判定音符 → 外圈 6 层蓝光 | `#57c8ff` |

**不含**：判定环、屏震、HUD（Combo/分数/进度条）—— 游戏里这些属于「玩法反馈」，故事板出片不需要。
需要的话可以加开关，`stage_view.gd` 里是 `_draw_fx()` / `_draw_hud()` 两块。

## 3. 界面

```
┌──────────────────────────────────────────────────────────────────────┐
│ 导入谱面 · 载入音频 · 打开/保存工程 · 导出整包 · 播放 · 撤销 · 截图/录制 │
├───────────────┬──────────────────────────────────┬───────────────────┤
│ 场景列表       │            舞台 16:9              │  属性             │
│ ＋解锁场/演出场 │  ─────────────────────────────    │  （选中图层/场景/  │
│ ＋谱面场       │  播放条 + 时间码 + 吸附 + 缩放     │   后处理）         │
│ 谱面（只读）   │  时间轴：场景带 + 当前场景的行      │  后处理 Shader     │
│ 添加图层/模板  │                                  │  操作说明         │
│ 图层列表       │                                  │                   │
└───────────────┴──────────────────────────────────┴───────────────────┘
```

- **舞台**是固定 **1280×720** 的虚拟分辨率，窗口怎么缩放比例都不变（CSS `object-fit: contain`）
- **播放头跑到别的场景时，左边编辑面板会自动跟着切过去**（编辑目标和画面始终对得上）
- 「**谱面基准**」下拉：谱面的 `x / y` 是按多大的画幅调的。默认 **350 = 游戏逻辑舞台**
  （和 Godot 的 `stage_view.gd` 完全一致）；换成 380 / 1280 / 1920 时，故事板会按 `350/基准` 把 x/y 缩回逻辑空间
- 谱面卡片下面有「**曲绘作者**」输入框（谱面格式里没有这一栏，所以存在故事板的 `meta.coverArtist`），可以在文字里用 `{illust}` 引用
- 左栏「**音频**」组：文件名、**音量滑条（0~100%）**、**静音**（只影响本机试听）、换个音频
- 状态栏显示：时间 / 当前场景 / 图层数 / 后处理数 / 谱面 / 当前生效的 Shader 权重

## 4. 图层

| 类型 | 画什么 | 主要参数 |
| --- | --- | --- |
| **文字** | 标题 / 歌手 / 难度 / 任何文案，9 种特效 | 文本（支持换行）、字体、字号、字重、字距、行高、对齐、颜色、发光、渐变两色、描边、打字速度 |
| **解锁动画** | 7 种成品演出（见 §5.2） | 预设、标题、副标题、主色、辅色、尺寸 |
| **图片** | 曲绘 / LOGO / 贴纸（选图后以 dataURL 存进工程） | 资源名、宽度 |
| **视频** | 导入自己的 mp4 / webm 当解锁动画或任意全屏画面（默认 `cover` 铺满；播放头拖动时视频跟着 seek；**自带音轨会出声**） | 资源名、宽度、适配、播放速度、音量、静音 |
| **形状** | 方框 / 横线 / 圆 / 圆环 / 网格 | 宽、高、圆角、线宽、填充、网格数、颜色 |

公共参数：**开始 / 结束**（场景内秒）、**X / Y**（0~1 归一化，`0.5,0.5` = 舞台正中，**y 向下**）、
**缩放 %**、**旋转 °**（顺时针）、**透明度 %**、**混合模式**、**显示**、**入场 / 出场**（见 §6）。

> 「＋ 解锁动画」在谱面场里点的话，会自动**新建一个解锁场**放进去 —— 解锁动画本来就不该压在谱面上。

## 5. 特效

### 5.1 文字特效（9 种）

| id | 名字 | 表现 |
| --- | --- | --- |
| `plain` | 普通 | 实心字 |
| `glow` | 霓虹发光 | 光晕 + 清晰实心双层，强度由「发光」控制 |
| `glitch` | 故障错位 | 每字随机横竖偏移 + 红/青双色残影 |
| `type` | 打字机 | 逐字露出 + 闪烁光标，速度 = 每秒多少字 |
| `perchar` | 逐字弹入 | 每字错开 0.045s，`outBack` 弹一下 |
| `wave` | 波浪 | 每字上下正弦 + 轻微旋转 |
| `outline` | 描边 | 先粗描边再填色 |
| `gradient` | 渐变填充 | 从「渐变起」到「渐变止」的线性渐变 |
| `shake` | 抖动 | 每字高频小幅抖动 |

### 5.2 解锁动画（7 种预设）

| id | 名字 | 演什么 |
| --- | --- | --- |
| `tape` | 磁带插入 | 磁带滑入 → 压下「咔」一下（冲击环）→ 卷轴转 + 进度条 → 盖「UNLOCKED」章 |
| `scan` | 扫描解锁 | 边框亮起 + 扫描光带上下扫，扫过的地方曲名才亮 → `SCAN COMPLETE` |
| `progress` | 进度解锁 | 进度条冲到 100% + 刻度 + 百分比 → 闪白 + 「解锁完成 难度 等级」 |
| `shards` | 碎片汇聚 | 34 片碎片从四周飞入拼成标题框 → 曲名淡入 |
| `chain` | 锁链破碎 | 挂锁越抖越凶 + 裂纹 → 冲击波 → 碎片飞散 → 曲名浮现 |
| `shutter` | 快门开启 | 四片快门从中心拉开，露出后面的标题 + 边框角标 |
| `ring` | 环印盖章 | 外圈刻度 + 双层虚线环旋转收拢 → 中心徽章 `outBack` 弹出 |

- **标题**留空 = 用谱面 `meta.title`；**副标题**留空 = `difficulty + level`
- 解锁动画从所在场景的第 0 秒开始演；**要演在谱面之前，就放进解锁场**

### 5.3 Shader 后处理（14 种）

| id | 名字 | 效果 |
| --- | --- | --- |
| `none` | 无 | 占位 |
| `bloom` | 辉光 | 加权模糊后的亮部叠加 |
| `rgb` | RGB 分离（**立刻**） | 红蓝通道左右错位；进区间就是满强度，没有缓入缓出 |
| `crt` | CRT 扫描线 | 扫描线 + 轻微 RGB 分离 + 暗角 |
| `wave` | 水波扭曲 | 时间驱动的正弦 UV 扰动 |
| `glitch` | 故障 | 横向条带错位 + 竖块跳动 + RGB 分离 |
| `heat` | 热浪 | 高频横向折射 + 少量水波 |
| `pixel` | 像素化 | UV 量化到 28×16 格子 |
| `posterize` | 色调分离 | 色阶从 64 压到 4 |
| `vignette` | 暗角 | 四角压暗（`smoothstep(0.86 → 0.24)`），不掺颗粒了 |
| `grain` | 颗粒 | 胶片颗粒（+ 一点点暗角） |
| `stretch` | 四角拉伸 |
| `zoomShake` | 放大抖动 | 进区间那一下瞬间放大（最多 18%）→ 0.22s 内回弹到原样（末尾略小于 1 = 过冲抖一下）；抖动幅度也只在这瞬间 |
| `dream` | 梦幻柔光 | 柔和辉光 + 轻微水波 + 微颗粒 |
| `flash` | 反色闪白 | 反色 + 辉光（做闪白用） |

一个 GLSL 主着色器 + **逐层 pass**：同一场里多条重叠时**一条 = 一层**，按列表顺序各跑一遍全屏 pass（离屏 A/B 轮转），
所以叠 3 条 RGB 分离就是分 3 次做、顺序也有意义（先辉光后暗角 ≠ 先暗角后辉光）。
每条有 **预设 / 起 / 止 / 强度 / 软边 / 缓动**；
软边 = 两头渐入渐出占时长的比例（0~0.49）。

后处理列表是**折叠**的：每条只显示一行（预设 + 起止/强度摘要 + ✕），**点哪条展开哪条**，展开的里面才有起/止/强度/软边/缓动，
非「立刻」型还会画一条**缓动曲线**（青色实线 = 当前缓动，灰色虚线 = 线性参考）。

**立刻型**（预设上带 `instant: true`，目前是 `rgb`）：忽略软边，进区间就满强度、出区间立刻消失——
RGB 分离要“啪”一下分开，而不是慢慢撑开。列表里这类效果的「软边 / 缓动」会置灰并标注。

## 6. 运动：出入场 + 关键帧

入场 11 种：`none / fade / slideUp / slideDown / slideLeft / slideRight / pop / zoom / zoomOut / blurIn / wipe`
出场 10 种：`none / fade / slideUp / slideDown / slideLeft / slideRight / pop / zoom / blurOut / wipe`

关键帧 5 条独立通道：**X / Y / 缩放 / 旋转 / 透明度**，语义和制谱器的轨道事件一致：

- 取「`start ≤ t` 且 `start` 最晚」的那条；进行中从 `from` 缓动到 `to`
- **跑完保持 `to` 不回弹**，直到同通道下一条开始
- 通道没事件 / 事件还没开始 → 用图层静态值

属性面板「关键帧」区：选通道 → 「＋ 在播放头」按当前值打点 → 直接改 `起 / 止 / 值 / 尾值`。

## 7. 时间轴

- 最上面是**场景带**：每场一块，显示名字和时长；谱面场里还叠了音符密度（只读）
- 点场景块 = 切到那一场并跳到它的开头；拖**非谱面场**块的右边缘 = 改场景时长
- 场景带上的**谱面密度**按当前视图窗口分桶，所以缩放 / 平移时尖刺跟着一起动（之前是按整首谱面压进可见宽度，缩放后纹理不动还错位）
- 下面只显示**当前场景**的图层行 + 后处理行；**后处理按时间重叠自动分层**（剪辑软件那套：不重叠的挤在同一行，
  只有和同一层里已有的条重叠时才新开一行），行标签写 `<序号>. 预设名 + …`；别的场景区域压暗；层多时行会先压矮（21 → 15px），
  还放不下就**纵向滚动**（鼠标停在行区域滚轮），「后处理」行始终点得到
- 拖图层条中间 = 整体平移（长度不变），拖两端 = 改起止；都会吸附到拍。位移按**相对按下点的总距离**算，
  所以条是 1:1 跟手的（之前按每帧增量算，拖 40px 只走十几像素，像拖不动）
- 触摸屏 / 手写笔也能拖：时间轴设了 `touch-action: none`，`pointercancel`（滚动 / 失焦）会安全收尾
- **条太窄（< 18px，比如缩到整首看）时整条都算平移**，不做边缘裁剪 —— 想改长度先放大；
  条最细也会画/判成 10px 宽，缩远了也点得中
  - **解锁场 / 演出场**：拖过场景末尾会**自动把场景加长**（条不会被压扁）
  - **谱面场**：长度由谱面决定，条贴住末尾就停（不会越界）
- 拖后处理条 = 同上；点空白/标尺 = 移动播放头（按住拖着走，播放头跟着）
- **后处理行空白处拖一下** = 直接拉出一条新后处理（长度由你拖的距离决定；只点不拖仍是移动播放头）
- **Shift + 拖动 / 中键拖动** = 平移视图（剪辑软件习惯），不打乱播放头
- **右键**时间轴上的**图层条 / 后处理条 / 场景带** = 删掉那一条（`Ctrl+Z` 撤销；最后一场不能删）
- 时间轴**底部有横向滚动条**：thumb 宽度 = 可见时长 / 总时长，拖它（或点它）就能左右移动时间轴；滚轮也能横向平移。全片都可见时滚动条会铺满并变灰
- `Ctrl`+滚轮 = 缩放，滚轮 = 左右平移，底下的「缩放」滑条也能拉
- 总时长之后的区域压暗 + 琥珀色虚线标出结尾

## 8. 模板

「模板」下拉 + 「套用到播放头」= 把一套演出**铺满当前场景**：

| id | 名字 | 内容 |
| --- | --- | --- |
| `opening` | 开场标题卡 | 曲名发光滑入 + 艺术家 + 揭开横线 + 辉光 |
| `unlock` | 解锁演出 | 磁带插入 + 「解锁成功」打字机 + 故障闪 + 辉光 |
| `result` | 结算卡 | 衬底 + 难度渐变放大 + `LEVEL xx` + 暗角颗粒 |

- 模板比场景长时会**按比例压进场景**（结构保留），例如 2.6 秒的解锁场放 5 秒的解锁演出会被压到 ~52%
- 占位符自动替换：`{title}` `{artist}` `{charter}` `{difficulty}` `{level}` `{illust}`（曲绘作者）

```json
        }
      ],
      "shaders": [
        { "id": 1, "preset": "glitch", "start": 1.1, "end": 1.9, "amount": 100, "ramp": 0.35, "ease": "inOutSine" }
      ]
    },
    {
      "id": 2, "kind": "chart", "name": "谱面", "length": 0,
      "layers": [], "shaders": []
    },
    {
      "id": 3, "kind": "free", "name": "片尾", "length": 3.6,
      "layers": [], "shaders": []
    }
  ]
}
```

字段要点：

- `scenes[]` 的**顺序就是播放顺序**；`kind` 是 `unlock` / `chart` / `free`
- **谱面场的 `length` 恒为 0**，实际时长跟随 `chart.duration`（改它无效）
- 其它场景 `length` 是 0.1 ~ 3600 秒
- 图层 / 后处理的 `start` / `end` 是**场景内本地时间**
- `stage.length` 是可选的总时长上限：`0` / 缺省 = 用所有场景之和
- `meta.coverArtist` = **故事板自己的曲绘作者**。谱面 `meta.illustrator`（制谱器「曲绘画师」一栏）是参考值：
  故事板填了就用故事板的，没填就退回谱面的；`{illust}` 都按这个顺序取，空值时替换成空串
- `stage.chartBase` = **谱面基准画幅宽度**（默认 `350` = 游戏逻辑舞台，高 = 宽 × 9/16）。谱面的 `x / y` 是绝对像素，
  故事板会先按这个尺寸把谱面画一遍、再整体放大到 1280×720 —— 这样两边的相对位置才一致。
  改成 `1280` 就变成「按 1280 宽摆」。老工程没这个字段时按 350 处理
- `stage.volume` = **故事板自己的播放音量**（0~100，默认 100）。它只作用在播放/录制用的音频元素上，
  **不改谱面的 `audio.volume_db`**；静音是本地开关，不写进工程
- `assets` 只留 `data:` 开头的；未知类型/预设一律退回默认值，**读脏数据不抛异常**

旧版工程（`version: 1`，图层直接挂在根上的 `layers` / `shaders`）也能打开：
会自动收进一场（有谱面就是谱面场），并给一条迁移提示。

## 14. 已知边界

1. **工程里没有谱面** —— 重开工程要再导入一次谱面；指纹不一致会提示。
2. **谱面场只能有一个**（一段故事板里谱面只放一次）；想要两段谱面就做两个工程。
3. **非谱面场的时长要自己管**：改场景时长不会自动缩放里面的图层（拖长了就会留白，拖短了会把后面的图层剪掉）。
4. **没有 WebGL 时** 后处理自动关掉（其余照常），状态栏会说明。
5. **图片存 dataURL**，图多/图大会让工程文件变大。
6. **撤销快照不含资源内容**：撤销栈只存工程结构（约 8KB/步），视频 / 图片的 dataURL 不进快照（只记文件名），
   撤销时资源用内存里现有的（资源只增不减）。撤销上限 40 步。别再往里塞资源内容 —— 那会把标签页撑爆。
7. **导出整包时资源单独成文件**：视频 / 图片放在 zip 的 `assets/` 里（`storyboard.json` 只存 `assets/xxx` 相对路径），
   所以解压后能看到 `assets/Unlock.mp4`；网页里「打开工程」选 zip 也能把资源读回来。
   注意 Godot 只能播 Theora `.ogv`（见 `tools/unlock_to_ogv.ps1`），mp4/webm 放进去游戏读不了。
8. **视频也存 dataURL**：20MB 以上导入会卡一下、工程 `.rstory.json` 会很大（导出整包时视频随 `storyboard.json` 一起走）。
   长视频建议先剪短 / 压到 720p 再导；播放时视频走浏览器解码，`cover` 会裁掉画面边缘。
7. **视频时长自动对齐**只会在**场景长度之内**生效：视频 8 秒、解锁场只有 2.6 秒，图层最多拉到 2.6 秒。
   想要完整放完，先拖解锁场的右边缘把它拉长（或把视频放进谱面场）。
6. **录制音轨**受浏览器策略限制，不一定成功（失败只录画面）。
7. 目前没有：场景之间的转场（淡入淡出/叠化）、场景分组、遮罩、曲线编辑器（关键帧只有单段缓动）。

## 谱面预览：父线 / 子线

故事板里的谱面场和制谱器、游戏用**同一套轨道坐标系**（`web/js/chart_stage.js` 的 `laneGeom`）：

- 轨道有父线时，`x` / `y` / `rotation` 都是**父线坐标系里的相对量**：`x` 沿父线横向、`y` 沿父线轨道方向（向上为正）、旋转叠加
- 父线本身可以随时间变（`parent` 事件通道），子线整条跟着动
- 防环：父链上指回自己就当没有父线；最多回溯 8 层

对应实现：`laneGeom(chart, i, t, halfW, xyScale, depth, seen)`（和 `web/js/editor.js` 的 `laneGeom` 同一套公式）。
