# 网页版制谱器

纯前端，没有构建步骤、没有依赖。**双击 `index.html` 就能用**（Chrome / Edge 都行）。

> 游戏侧要读谱、要跟这套渲染对齐？看 [`../docs/`](../docs/README.md)：
> [谱面格式](../docs/CHART_FORMAT.md)、[玩法/渲染规范](../docs/GAME_INTEGRATION.md)、
> [Godot 指南（含 GDScript）](../docs/GODOT_GUIDE.md)。

> **要给谱面做「演出包装」**（解锁动画、文字特效、Shader、截图 / 录屏）：
> 双击同一目录下的 [`storyboard.html`](storyboard.html) —— 故事板制作器，
> 详细说明见 [STORYBOARD.md](STORYBOARD.md)。
> 它**只读谱面**：工程文件里只存文件名 + 指纹，不存谱面内容；导出整包时把 `chart.json` 原样复制。

## 这一版有什么

- 竖版时间轴：**左半边编辑音符，右半边编辑事件**，横轴是轨道，纵轴是时间，
  判定线在下方 84% 处，音符从上往下落
- **左侧音符密度条**：一根窄带把整首歌的音符密度画成柱状（越密越宽、颜色从青到紫到粉），
  点/拖它就跳到那个位置；空谱面时显示「空」。
  **载入音频后窄带按整首歌算**（0 → 音频末尾，减去 offset），所以谱面写到 30 秒、
  歌有 3 分钟的谱子，上面那段会显示成空白 —— 密度条的顶端就是歌曲尾部。
- 放置 / 拖动 / 改长度 / 删除 / 右键拖画 hold / 双击换类型
- **Shift 框选**：在音符区按住 `Shift` 拖出矩形，框中的音符一批选中；之后一起拖、一起删、一起换轨
- **事件也能框选**：事件区 `Shift` 拖 = 框选事件（`Ctrl` 点 = 单个加选/取消），`Ctrl+C` / `Ctrl+V` 复制粘贴到播放头，`Del` 批量删，拖任意一个整组平移
- **音符也能复制粘贴**：在音符区框选后 `Ctrl+C`，把播放头挪到目标位置 `Ctrl+V` —— 轨道、类型、长条长度原样带走，相对间距保持不变
- BPM 网格 + 吸附（1/1 ~ 1/16 拍），改 BPM 不会挪动已有音符
- 载入本地音频（ogg / mp3 / wav），空格播放暂停，播放头跟音频走
- **打击音**：`web/audio/hit.wav`（0.144 秒，44.1kHz），放音符时响一声，播放时音符过判定线逐个响；
  左边栏「打击音」勾选框可以关掉
- 音频偏移（音画对齐）、**音乐音量 / 打击音音量滑条**、**播放倍速（1× / 0.75× / 0.5× / 0.25× 慢放，保调）**、可视秒数（时间轴缩放）
- 1~16 轨随便改，改少了会把越界音符挪到最后一轨并提示
- **轨道判定区**：完全由**事件区第 7 列**决定（值 `0=无 / 1=左 / 2=右`），可以随时间切换；
  没有事件时用轨道自带的默认值 `none`
  - 无（白 `#ffffff`）→ `A S D F J K L ;`
  - 左（紫 `#b06bff`）→ `A S D F`
  - 右（黄 `#ffd166`）→ `J K L ;`
- **轨道数**：在左侧「时间轴」组里改（1~16）；一屏最多显示 6 条，多余的用画布下方的滚动条翻
- **每条轨道 5 组舞台参数**（6 个数字，坐标算一组）：
  | 参数 | 含义 | 默认 | 范围 |
  | --- | --- | --- | --- |
  | X / Y | 相对**舞台正中**的像素偏移（X 右为正，**Y 上为正**） | 0 / 0 | -2000 ~ 2000 |
  | 透明度 | 越小越透明，`0` = 完全隐藏（**只藏轨道本体和判定线，不藏音符**），`100` = 完全不透明 | 0 | 0 ~ 100 |
  | 音符流速 | `10` = 1.00×，**平方曲线**（`20` = 4×、`30` = 9×、`50` = 25×、`100` = 100×），`0` = 停住 | **10** | 0 ~ 100 |
  | 轨道长度 | `10` = 标准长度（判定线 → 画面顶），`0` = 只剩底部判定线，`100` = 十倍长 | **10** | 0 ~ 100 |
  | 旋转角度 | 度，顺时针为正，0 = 竖直向上 | 0 | -3600 ~ 3600 |

  **每条轨道的位置就是绝对偏移**（Phigros 那套）：所有轨道默认都堆在舞台正中、互相重合，
  想让它们排开就自己填 X —— 比如 4 轨左右对称：`-96 / -32 / 32 / 96`。
  改这些只在**预渲染窗口**里看得到效果 —— 左边的时间轴是编辑用的平面网格，永远等宽竖排
  （不然就没法放了）。

  这些**没有单独的输入框**：每新建一条轨道，6 个参数就各自在**起点铺一条默认事件**（0 ~ 0.5s，
  头尾都等于默认值，所以画出来不会动）。要改就点开事件区里对应那列的那条事件，
  改「头」「尾」——侧栏那套参数面板已经删掉了。

  > 注意：透明度默认是 `0` = 完全隐藏，所以**新建谱面时预渲染窗口里只有音符没有轨道**
  > （没音符时会有文字提示）。想让轨道现身就把对应轨道的「透明度」调大。
- **曲绘**：左边栏「音频」组里选一张图（png / jpg / webp），存进 `meta.cover`，
  导出时一起打进去；侧栏有 54×54 的缩略图预览
- **导出 zip**：`Ctrl+S` 下载一个 `.zip`，里面是 `chart.json` + 音频 + 曲绘三样东西，
  文件名取曲名（如 `Neon Pulse.zip`）。zip 是 store 模式（不压缩），因为音视频本来就已经压过了
- 撤销 / 重做（整份快照，一次操作一步）
- **事件（轨道动画）**：时间轴右半边是 **7 列 = 6 个参数 + 判定区，各自的独立通道**
  （X / Y / 透明度 / 旋转 / 流速 / 长度）；在某一列里拖一下就画一个只改这个参数的事件，
  头尾各一个值 + 一条缓动曲线。运行逻辑跟长条音符一样：事件跨过的时间段里参数从「头」插值到「尾」。
  事件区底下的 `1 2 3 4` 按钮用来切换当前编辑哪条轨道的动画。
  每个事件条**横轴是值、竖轴是时间**：拖两端 = 左右改值 / 上下改时间，拖中间 = 整体平移
- **打开**：`Ctrl+O` 支持 `.json` 和 **`.zip`**（编辑器导出的那种，会自动把里面的音频和曲绘一起读回来；系统右键压缩的 deflate 包也能开）
- 校验谱面：负时间 / 轨道越界 / 0 长度 hold / 同轨重叠
- **左侧一屏最多 6 条轨道**：超过 6 条时画布**下面**会出现一条真的滚动条（◀ 滑轨 ▶ + 3–8 / 8），拖滑轨或点按钮都能翻；点事件区的轨道按钮也会自动滚过去
- **长条随流速变长**（只在预览里）：长条长度 = duration × 基础速度 × 流速倍率；流速 0 时回退到最近的非零流速，不会缩成一条线；时间轴永远按时间画
- **右侧 16:9 预渲染窗口**：按游戏的舞台语义把谱面画出来（轨道以舞台正中为原点、判定线在 85% 高度、
  音符从上往下掉），播放时跟着音频实时走；「可视秒数」同时管这里和编辑区的下落速度。
  线的粗细都在 `js/editor.js`：轨道半宽 = `min(屏宽×0.05, 屏宽×0.43/轨数)/2 − 0.5`，
  音符半宽再减 1，音符半厚 `NOTE_TH = 1.25`。想再调细就改这几个数。

## 谱面格式

跟 `docs/CHART_FORMAT.md` 的 rchart 是同一套，这一版只用基础字段：

```json
{
  "format": "rchart",
  "version": 3,
  "meta": { "title": "…", "artist": "…", "charter": "…", "illustrator": "…", "difficulty": "HARD", "level": 8, "cover": "cover.png" },
  "audio": { "file": "song.mp3", "offset": 0.0, "volume_db": 0.0, "hit_volume_db": -3.0 },
  "timing": { "bpm": 150, "beat_offset": 0.0 },
  "stage": { "lane_count": 4, "highway_length": 2.0 },
  "lanes": [
    { "name": "Lane 1", "color": "#ffffff", "judge_zone": "none",
      "x": 0, "y": 0, "alpha": 0, "speed": 0, "length": 0, "rotation": 0 }
  ],
  "notes": [
    { "id": 1, "time": 1.0, "lane": 0, "type": "tap" },
    { "id": 2, "time": 1.4, "lane": 1, "type": "hold", "duration": 0.8 }
  ]
}
```

- `meta.illustrator` = 曲绘作者（侧栏「曲绘画师」），缺省空串；导出时一起写进 chart.json
- 时间单位是**秒**
- 音符类型 `tap` / `hold` / `flick` / `mine`，`duration` 只有 hold 有意义
- `judge_zone` 是 `none` / `left` / `right`；写错或没有就按 `none` 处理
- **染色规则**：`judge_zone` 不是 `none` 时，用判定区颜色画（紫 / 黄），轨道自己的 `color` 只在 `none` 时生效（默认白）
- **轨道编号**：预览里每条轨道判定线外侧标着 1 2 3 …（跟着轨道的颜色和旋转走，透明度 0 时也保留，方便定位）
- **可视秒数 / 预览秒数 分开**：可视秒数只管左边时间轴看多少秒；预览窗口的下落速度由「预览秒数」单独控制（默认 2s，数值越小落得越快）
- **尺寸**：预览里轨道宽 = `min(屏宽×5%, 屏宽×43%/轨道数) × 1.6`，音符厚度 4px；想整体再大/再小改 `editor.js` 顶部的 `PV_SCALE` 和 `NOTE_TH`
- 轨道参数 `x / y / alpha / speed / length / rotation` 缺省都是 `0`，超出范围会被夹住；读游戏侧时可以直接用
  `RChart.laneAlpha()` / `laneSpeed()` / `laneLength()` 换算成实际值
- 读入时很宽容：缺字段用默认值，`lane` 越界夹住，类型不认识当 tap，`duration<=0` 的 hold 当 tap，负时间夹到 0，id 重复自动续号

给游戏侧判定用的键位（`core.js` 里也有导出）：

| judge_zone | 颜色 | 能判定的键 |
| --- | --- | --- |
| `none` | 白 `#ffffff` | `A S D F J K L ;` |
| `left` | 紫 `#b06bff` | `A S D F` |
| `right` | 黄 `#ffd166` | `J K L ;` |

```js
const keys = RChart.laneKeys(lane);   // → ['A','S','D','F']
const color = RChart.displayColor(lane);  // → '#b06bff'
```

## 事件（轨道动画）

右半边是事件区，**7 列 = 6 个参数 + 判定区各自的通道**（底下标着 X / Y / 透明度 / 旋转 / 流速 / 长度 / 判定区）。
每个参数各管各的：你在 X 列画的事件只改 X，不会碰到 alpha。

- 某一列空白处**上下拖** = 在这条参数通道里画一个事件，头尾值默认都等于当前值（画完不会动）
- 拖**两端**改起止时间；拖**中间**整体平移；**右键**删除
- 选中后右下角「事件（动画）」面板里改「头」「尾」的值 + 缓动，改完立刻在预渲染窗口里动
- 缓动下拉下面是**曲线预览**：虚线是对角线（线性参考），蓝线是当前缓动，粉点是播放头在该事件上的进度
- 事件区底下的 `1 2 3 4` 按钮 = 切换当前编辑哪条轨道的动画
- 事件跑完后**保持尾值不回弹**，直到同一通道的下一条事件开始（PhiEdit 那套）

```json
"events": {
  "x":      [ { "start": 2, "end": 6, "ease": "inOutQuad", "from": -60, "to": 60 } ],
  "alpha":  [ { "start": 2, "end": 4, "ease": "outCubic",  "from": 0,   "to": 100 } ],
  "rotation":[ { "start": 4, "end": 8, "ease": "outBack",  "from": 0,   "to": 90 } ]
}
```

求值规则（`RChart.laneParamsAt(lane, t)`）：**逐条通道**找到「起点 ≤ t 且起点最晚」的那条事件，
`t` 落在里面就按 `ease((t-start)/(end-start))` 从 from 插值到 to；过了 end 就取 to；
那条通道没有事件就用轨道的静态值。

内置缓动：`linear / step / inSine / outSine / inOutSine / inQuad / outQuad / inOutQuad /
inCubic / outCubic / inOutCubic / inQuart / outQuart / inOutQuart / inExpo / outExpo / inOutExpo /
inBack / outBack / inOutBack`，另外支持自定义 `bezier(0.25, 0.1, 0.25, 1)`（同 CSS cubic-bezier）。
