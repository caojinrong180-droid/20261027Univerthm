      属性

      后处理 Shader 0

      多条 Shader 时间重叠时逐层叠加：一条 = 一层，按列表顺序各跑一遍（先辉光后暗角 ≠ 先暗角后辉光）。 「软边」控制两头渐入渐出的比例，0 = 一直是满强度。

      操作

      • 空格 = 播放 / 暂停，Home/End 跳首尾
      • 时间轴上拖图层条 = 整体平移，拖两端 = 改起止
      • 右键时间轴上的图层条 / 后处理条 / 场景带 = 删除它（Ctrl+Z 撤销）
      • 时间轴空白处拖 = 移动播放头（拖到哪停到哪）
      • 后处理行空白处拖一下 = 拉出一条新的后处理（只点不拖 = 移动播放头）
      • Shift+拖动 / 中键拖动 = 平移视图
      • Ctrl+滚轮 = 缩放时间轴，滚轮 = 左右平移
      • Del = 删除选中图层 / Shader
      • Ctrl+D = 复制图层，[ ] = 调层级
      • Ctrl+Z / Ctrl+Shift+Z = 撤销 / 重做
      • Ctrl+S = 保存工程
