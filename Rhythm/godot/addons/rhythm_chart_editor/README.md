# Rhythm Chart Editor

Godot 4.x 的可视化制谱器插件：编辑 `rchart` JSON 谱面，支持 **N 轨**，每条轨道可独立设置
**位移 / 旋转 / 透明度 / 长度**。

## 安装

1. 把整个 `rhythm_chart_editor/` 目录拷到你工程的 `res://addons/` 下：

   ```
   你的工程/
     addons/
       rhythm_chart_editor/
         plugin.cfg
         plugin.gd
         core/
         ui/
   ```

2. 打开 Godot：**项目 → 项目设置 → 插件**，勾选 **Rhythm Chart Editor**。
3. 编辑器顶部（2D / 3D / Script 那一排）会出现 **制谱器** 标签页。

> 插件是以「主屏幕」注册的，不是 dock —— 时间轴 + 舞台预览需要整块工作区。

## 界面

```
┌──────────────────────────────────────────────────────────────────────┐
│ 新建 打开 保存 另存为 │ ⏮ ▶播放 │ 吸附 │ 滚动 上→下 │      校验谱面 │
├──────────────┬───────────────────────────────┬───────────────────────┤
│ 谱面信息     │  1 Outer │ 2 Inner │ 3 Inner   │   舞台预览            │
│ 音频         │                               │  （轨道可拖可转）     │
│ 时间轴/BPM   │   时间轴：竖轴=时间           ├───────────────────────┤
│ 舞台         │   横轴=轨道（左→右）          │   轨道检查器          │
├──────────────┴───────────────────────────────┴───────────────────────┤
│ 时间 · 音符统计 · BPM · 时长 · ⚠提示                    文件路径 ●未存 │
└──────────────────────────────────────────────────────────────────────┘
```

时间轴是**竖版**的：横轴是轨道（左→右，和游戏键位一致），纵轴是时间。
判定线固定在画布**下方约 3/4 处**，**线上方全是"未来"** —— 音符从上面出现、落到判定线（downscroll，默认）。
工具栏的「滚动 上→下 / 下→上」可以一键翻成判定线在上方、音符从下往上。

## 时间轴操作（竖版）

| 操作 | 效果 |
| --- | --- |
| 左键点轨道区空白 | 在该时间点放一个 Tap，并直接进入拖动 |
| 左键拖音符 | 改时间（上下）/ 改轨道（左右） |
| 左键拖长条**尾端** | 改长条长度（尾端在"未来"那一头，下滚时在上方） |
| 右键点音符 | 删除 |
| 双击音符 | 循环切换类型 tap → hold → flick → mine |
| 滚轮 | 翻页：每次一拍，落点自动对齐最近的节拍线 |
| 中键拖 | 拖动时间 |
| Ctrl + 滚轮 | 缩放（以光标处为锚） |
| 拖左侧刻度栏 | 移动播放头 |
| `Del` | 删除选中音符 |
| `←` `→` | 选中音符换轨（横轴是轨道） |
| `↑` `↓` | 播放头按吸附步进 |
| `Esc` | 取消选择 |
| 按住 `Alt` 放/拖 | 临时关闭吸附 |

## 事件层（在时间轴上直接摆事件）

时间轴右半边是**事件区**，五列并排、和底部标签一一对应：

```
X轴 | Y轴 | 角度 | 透明度 | 长度
```

左边音符区、右边事件区共用同一套时间坐标 —— 滚动、缩放、吸附、对齐节拍线完全同步。

- 某列空白处**按住左键上下拖** = 生成一条该属性的事件（拖多长就多长）
- 拖事件条两端把手 = 改开始 / 结束时间；拖中段 = 整体平移
- 右键事件条 = 删除
- 点某列 = 把右侧「事件（动画）」参数窗切到该属性（起止时间 / 起止值 / 缓动 + 缓动曲线）
- 底部五个标签既是列名，也是焦点指示：当前列会高亮

右侧面板和时间轴改的是同一份数据，任一边改动另一边立刻跟上。

## 舞台预览操作

拖轨道是最直观的调法：

| 操作 | 效果 |
| --- | --- |
| 左键拖轨道 | 平移（改 `position`） |
| 右键拖轨道 | 让轨道朝向鼠标（改 `rotation_deg`） |
| 点轨道 | 选中该轨道，右侧检查器同步 |

透明度、长度、颜色、可见性在右侧 **轨道检查器** 里改，数字会实时反映到预览和 JSON。

### 判定区（白 / 紫 / 黄）

轨道的 `judge_zone` 决定这条轨道上的音符能被哪些键判定，检查器里的「判定区」下拉可直接改：

| 判定区 | 颜色 | 允许的键 |
| --- | --- | --- |
| `None` | 白 `#ffffff` | `A S D F J K L ;` 任意键 |
| `Left` | 紫 `#b06bff` | 只有 `A S D F` |
| `Right` | 黄 `#ffd166` | 只有 `J K L ;` |

设了判定区后，时间轴、舞台预览、游戏渲染都会用判定区的颜色画（轨道自身的 `color` 只在「无」时生效）。
新建轨道默认是**白色 + 无判定区**。

### 事件（动画）

轨道可以像 Phigros 那样随时间动起来，用 **事件** 描述（PhiEdit 那套模型）：
一条事件 = 起止时间 + 起止值 + 缓动。右侧「事件（动画）」面板（标题右边的 ▼ 可以收起整个事件层）：

```
事件（动画）                          ▼
属性 [移动 X ▾]
┌ 值随时间曲线 ┐  ← 粉线是播放头
└──────────────┘
0.00s → 8.00s  -50.0 → -220.0  inOutQuad   ← 点一行选中它
8.00s → 16.00s -220.0 → -50.0  inOutQuad
起始时间 [0.00 s]   结束时间 [8.00 s]
起点值   [-50]      终点值   [-220]
缓动     [inOutQuad ▾]
┌ 缓动曲线 ┐  ← 这条缓动函数的形状
└──────────┘
```

事件的**新建和删除都在时间轴的事件区里做**（左键拖 = 新建，右键 = 删除），
右侧这个面板不提供按钮，列表会跟着时间轴的增删自动更新。

操作：

1. 「属性」选 `移动 X / 移动 Y / 旋转 / 透明度 / 长度`
2. 播放头放到目标时间 → **「+ 事件」**（新建 1 拍长的事件，起止值 = 当前值）
3. 在列表里点一条，下面就能改它的**起止时间 / 起止值 / 缓动**
4. 「复制」= 接着这条往后复制一段；「拆分」= 在播放头处切成两条；「删除」= 删掉这条

缓动支持 `linear / step / inSine / outSine / inOutSine / inQuad / outQuad / inOutQuad /
inCubic / outCubic / inOutCubic / inExpo / outExpo / inBack / outBack`，
也可以直接手写自定义曲线 `bezier(0.25, 0.1, 0.25, 1)`（同 CSS cubic-bezier）。

- 事件之间保持上一条的 `to`，不会自动回弹 —— 要回弹就再写一条反方向的事件。
- 舞台预览会**跟着播放头实时播放事件动画**。
- 属性面板里的 `X / Y / 旋转 / 透明度 / 长度` 是**静态值**：该属性有事件时以事件为准。
- `透明度` 是 **0~255** 整数（0 全透明，255 不透明），事件里的值也是 0~255。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + N` | 新建 |
| `Ctrl + O` | 打开 |
| `Ctrl + S` / `Ctrl + Shift + S` | 保存 / 另存为 |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做 |
| `Space` | 播放 / 暂停 |

播放头推进优先跟音频走（`AudioStreamPlayer.playback_position` + 混音补偿）；
没指定音频时用挂钟空放，方便先摆位置。

## 音频

「音频 → 文件」可以填 `res://` 路径，也可以点 `…` 选桌面上的音频文件
（`ogg` / `mp3` / `wav`）。不在项目里的文件也能试听，最终发布时建议改成 `res://`。

「偏移」用于音画对齐：**音频时间 = 谱面时间 + offset**。

## 数据流

```
所有控件 ──只改──> RhythmChartDocument ──changed 信号──> 时间轴 / 预览 / 状态栏 重绘
                                         │
                                         └─ 保存 = doc.to_dict() → JSON
```

- 撤销 = 整份 `to_dict()` 快照（`_push_undo`），够稳，不需要给每个操作写逆操作。
- 时间轴里一次拖拽 = 一个撤销步；检查器里连续拖数值做了 0.8 秒节流。

## 目录

```
plugin.gd                    EditorPlugin 入口（注册主屏幕）
core/rhythm_chart_note.gd    音符
core/rhythm_chart_lane.gd    轨道（含位移/旋转/透明度/长度）
core/rhythm_chart_timing.gd  BPM ↔ 秒、吸附、变速点
core/rhythm_chart_doc.gd     整份谱面 + 增删改 + 校验 + 快照
core/rhythm_chart_io.gd      JSON 读写的唯一入口
core/rhythm_chart_audio.gd   音频加载（含项目外文件）
ui/chart_editor_screen.gd    主界面、撤销、播放、文件对话框
ui/timeline_view.gd          时间轴编辑视图（自绘）
ui/stage_preview.gd          舞台预览（自绘，轨道可拖）
```

`core/` 不依赖编辑器，游戏运行时也能直接 `preload` 使用。

## 想接进自己的音游

1. 游戏侧读谱：`ChartIO.load_file(path)` → `doc.notes`（已按时间排序）。
2. 舞台渲染照 `examples/chart_stage_2d.gd` 里的公式算，保证和制谱器预览一致。
3. 判定逻辑自己写：音符只需要 `time` / `lane` / `type` / `duration`。

## 已知边界

- `lanes` 里没有「分组 / 图层」概念，轨道只有顺序 + 变换；需要更复杂舞台就自己加字段
  （格式对未知字段是忽略的，加字段不会破坏旧谱面）。
- 时间轴是"播放头锚定"的：视图永远以判定线为基准，翻页就是移动播放头（没有独立滚动了）。
- 舞台预览目前**不跟随**时间轴的滚动方向开关，仍是判定线在下的下滚视角（预览主要用来调轨道形状）。
- 撤销是整份快照，单份谱面很大（几万音符）时会占内存；常规音游规模（<5000 音符）没问题。
- 舞台预览从播放头**往回看 30 秒**找音符：超过 30 秒还没结束的变态长条，尾段不会画出来。
  换来的是每帧工作量与谱面总量无关（4000 音符实测约 6.9ms/帧）。

## 性能约束（改 UI 前先看）

这两个数字由 `test/run_perf_test.gd` 守着，退化就会红：

| 计数器 | 期望 | 含义 |
| --- | --- | --- |
| `stage_preview.debug_layout_calls` | 每帧 ≤ 1 | 包围盒 / 适配缩放只算一次，不能每个音符算一次 |
| `timeline.debug_notes_visited` | ≈ 视口内音符数 | 靠 `doc.index_at_time()` 二分跳过视口外音符 |
| `stage_preview.debug_notes_visited` | ≈ 回看窗口内音符数 | 同上，单趟遍历 + 排序提前 break |
