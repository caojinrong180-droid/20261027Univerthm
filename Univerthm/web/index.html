操作

  • 左键点空白 = 放 tap（按住可以直接拖）
  • 拖音符 = 改时间 / 轨道
  • 拖 hold 顶端 = 改长度
  • 右键点音符 = 删除
  • 右键空白上下拖 = 画一个 hold
  • 双击音符 = tap ↔ hold 切换
  • 按住 Shift 拖 = 框选音符（可整组拖/删）
  • 画布下面的滚动条 = 轨道超过 6 条时左右翻
  • Shift 拖 = 框选（音符区选音符、事件区选事件），Ctrl+C / Ctrl+V 粘贴到播放头
  • 滚轮 = 翻页（Shift 一整小节）
  • Ctrl+滚轮 = 缩放
  • 拖左侧刻度栏 = 移动播放头
  • 空格 = 播放/暂停
  • ← → = 选中音符换轨
  • ↑ ↓ = 播放头按吸附步进
  • Del = 删除选中
  • Ctrl+Z / Ctrl+Shift+Z = 撤销 / 重做
  • Ctrl+S = 导出 JSON
  • 判定区在事件区最后一列改（0=无 1=左 2=右）
  • 轨道参数 = 起点那条默认事件；轨道数在左边「时间轴」组里
  • 时间轴右半边上下拖 = 在那一列对应的参数通道里画事件
  • 拖事件两端 = 改起止时间，拖中间 = 整体挪
  • 右键点事件 = 删除
  • 事件区底部 1 2 3 4 = 切换编辑哪条轨道的动画
