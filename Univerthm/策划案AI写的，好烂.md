## 一句话概念

一座城市正在一点点失去声音。天空裂开一道细黑的缝，车流、人声、脚步一段段消失，最后连星星也碎了——只剩一颗不反射任何光的黑洞，安静地扩大。玩家是唯一还能“看见”残余旋律的人：每一下踩准的节拍，都是把世界从静默里拽回来的一格。

**核心体验：用节奏对抗静默。** 玩家不是在跟着歌跳舞，而是在用节拍替世界发声——这是本项目所有系统设计的出发点。

### 三根支柱

| 支柱 | 含义 |
| --- | --- |
| 静默即世界观 | 没有血条、没有失败画面，曲子一定播完。每一次 MISS 都不只是掉分，而是声音再一次被吞掉。 |
| 判定即表达 | 舞台是制谱器预渲染窗口的 1:1 复刻：轨道完全透明、判定线是一条实心圆角横条，视觉上不做任何多余装饰。 |
| 规则即叙事 | 第 3 首在打出成绩前显示为 `???`；第一次踏入会弹血红警告，那一趟 Esc 被锁死——真的“不能反悔”。 |

### 差异化

- **同构管线**：网页制谱器与游戏舞台共用一套几何公式（逻辑舞台 350×196.875、判定线 `y = round(H × 0.85)`），谱师看到的就是玩家看到的，不存在“预览好看、实机走样”。
- **掉落式叙事**：第 N 首通关掉第 N 篇剧情，收藏品页只显示已搜集内容——收集进度就是叙事进度，剧透问题由系统本身解决。
- **深空霓虹**：黑洞背景、切角面板、亚克力暂停、间歇性局部故障全部由 shader 与代码实时生成，不依赖 UI 切图，换皮只改一个调色板文件。

## 音游系统设计

### 判定窗口

以音符时刻为 0，单位毫秒，超出 ±220ms 即 MISS：

```
       MISS        BAD       GOOD    P    P+    P    GOOD       BAD        MISS
  ────────────┬──────────┬────────┬────┬────┬────┬────┬────────┬──────────┬────────
            -220      -140     -80  -55   0   +55  +80       +140      +220
```

| 判定 | 时间窗 | 权重 | 反馈 |
| --- | --- | --- | --- |
| **PERFECT+** | ≤ 55 ms | 100% | 浅紫判定环（与 PERFECT 同一效果，更亮） |
| **PERFECT** | ≤ 80 ms | 100% | 紫色判定环 |
| **GOOD** | 80 ~ 140 ms | 75% | 蓝色判定环 |
| **BAD** | 140 ~ 220 ms | 0% | 判定线闪红 0.42s；tap 原地渐隐，hold 降为半透明继续走 |
| **MISS** | > 220 ms | 0% | 无任何特效，音符直接过线消失（克制即风格） |

### 计分与评级

```
分数 = 1,000,000 × (Σ权重 / 可判音符数) + 10,000 × (Perfect+ 数 / 可判音符数)
理论满分 = 1,010,000
```

- 没有连击加成，分数只由准确率决定；**Bad 与 Miss 一样断连**
- ACC：游玩中按已判音符算，结算按全谱面可判音符算
- 评级 **S ≥96% / A ≥92% / B ≥85% / C ≥75% / D**
- 徽章：`ALL PERFECT+` / `ALL PERFECT` / `FULL COMBO`
- Early / Late 分开统计，结算界面单列一行——给硬核玩家一个继续抠的理由

### 舞台规格

| 量 | 值 |
| --- | --- |
| 逻辑舞台 | 350 × 196.875（16:9），直接铺满窗口，无黑边 |
| 判定线 | `y = round(H × 0.85) = 167`；底部一条实心圆角横条 |
| 轨道 | 4 轨宽 `30.6`；音符半宽 `13.81` / 半厚 `2.0` / 圆角 `2.4` |
| 轨道背景 | 完全透明，只画两侧 1px 描边 |
| 渲染顺序 | 轨道 → 音符 → 判定线（判定线最后画） |
| 音符换算 | `d = (note.time − t) × base_pps × speedMult` |
| 透明规则 | 透明度只藏轨道、不藏音符 |

### 谱面能力

- **六事件通道**：`x / y / rot / speed / alpha / length` + 可用键区 `zone`，带缓动插值，结束后保持尾值不回弹
- **父线系统**：轨道可挂到另一条轨道上（最多 8 层、自动防环），音符、判定线、长条、打击环跟着父线整体运动，`alpha / speed / length / zone` 仍用子线自己的值
- **缓动**：与网页版同一套数值，支持 `bezier(...)`
- **长条 hold**：任意键按着即保持（换手、换边都不算断），全松才断；吃到 BAD/MISS 不消失，压到 50% 透明继续走；尾巴被轨道截断时硬切断并自带圆角帽
- **打击特效**：三档（关 / 标准 / 强），多押 ±20ms 触发蓝色和弦光，MISS 无特效

### HUD

顶部进度条 + 左上 Combo + 右上 8 位补零分数与 ACC + 左下曲名 + 右下等级。

### 音频资产

| 资产 | 用途 | 行为 |
| --- | --- | --- |
| `difusion.mp3` | 菜单循环曲 | 开屏即 1.5s 淡入，穿主界面连续播；进选曲时交给试听接管 |
| 曲目自带音频 | 试听 / 游玩 | 选中曲目以 50% 音量交叉淡化试听，离开选曲立即停止 |
| `result.mp3` | 结算音乐 | 单次播放 0.9s 淡入，重试/选曲前 0.22s 淡出 |
| `hit.wav` | 打击音 | 击打音符响起 |
| `click.wav` | UI 点击 | 点击UI界面触发 |
| 校准节拍器 | 音画偏移测量 | 100 BPM、三轻一重 |

音乐在本项目里是**叙事资产**而不是背景：菜单曲决定“静默世界还剩下什么”，试听被杀死在神秘曲上（放音乐也算剧透），结算曲决定“这一局结束了没有”。

## 技术架构

### 分层

| 层 | 模块 | 职责 |
| --- | --- | --- |
| 数据层 | `rhythm_chart` | 读谱容错 / lane 参数 / 事件求值 / 父线坐标系 / 缓动 |
| | `judge` | 判定引擎（tap / hold / 连击 / 分数），纯逻辑 |
| | `chart_source` | 谱面发现与加载（zip / 文件夹 / json，音频与曲绘字节 → 资源） |
| | `story_source` | 剧情文本发现与读取（排版 / 编码 / 字数） |
| | `settings` | 玩家设置读写 |
| 表现层 | `stage_view` | 舞台渲染：`_draw` 三趟（轨道 → 音符 → 判定线）+ 打击特效 |
| | `gameplay` | 游玩流程：倒计时 → 音频时钟 → 判定 → 暂停 → 结算 |
| 界面层 | `palette` | 全部颜色（换皮先改这里） |
| | `theme_builder` | Theme：字体 / 按钮 / 面板 / 滚动条 / 进度条 |
| | `ui_kit` / `neon_ui` | 建控件的小函数 / 宇宙霓虹公共零件 |

### 关键约定

- 引擎 **Godot 4.7 / GL Compatibility**：低配兼容、导出快、Web 导出同样可行
- autoload **App** 统一管设置、谱面库、本次会话、结算数据与存档三条线
- 存档三分：`settings.cfg`（音量/偏移/名字）、`profile.cfg`（次数/平均分/通关/BEST/已踏入）、`collection.cfg`（剧情搜集）
- 谱面管线：网页制谱器（editor / core / storyboard）→ rchart（`chart.json` + 音频 + 曲绘 + 故事板 + 解锁视频）→ zip 拖进窗口即导入
- 列表顺序按文件名**数字自然序**（`9_` 排在 `10_` 前），调整顺序只需改文件名编号

### 质量保障

| 测试 | 内容 |
| --- | --- |
| `run_core_tests.gd` | 纯逻辑单测（数据层 + 判定 + 加载），headless |
| `smoke.tscn` | 界面 + 玩法冒烟：自动演示通关、几何常量、100% 准确率、结算与失败路径 |
| `realtime.tscn` | 真实音频时钟自检（需窗口 + 声卡） |
| `calibration_check.tscn` | 辅助测量浮窗（节拍器 / 早按晚按 / 取平均 / 写进偏移） |
| `tutorial_check.tscn` | 新手教程弹窗（按钮 / 图载入 / Esc / 记成看过） |
| `shot.tscn` | 截图自查 |

### 技术债

| 项 | 影响与处理 |
| --- | --- |
| `docs/CHART_FORMAT.md` 缺失 | README 多处引用但文档目录不存在——谱师上手门槛高，β 阶段必须补齐 |
| `web/` 只剩 js | 制谱器页面与样式表缺失，外部谱师无法独立使用——列为 β 首要交付 |
| 故事板图层未渲染 | 文字/图片/形状图层只做了解析；后处理 shader 已生效，先靠它撑氛围 |
| BPM 变速未支持 | 只取第一个 BPM 并告警；章节推进时再补 |
| 无排行榜 / 云存档 | 明确不在 α 范围，不阻塞发行 |

## 发行与风险

### 发行策略

- **平台**：Steam 免费本体 + 付费章节；itch.io 放序章 demo 引流
- **社区**：自制谱拖拽导入已实现，社区谱作长尾；开放制谱器与分享 zip
- **运营**：章节投票决定下一首重制曲；征集 Stra 笔记的玩家投稿
- **商业**：本体免费、章节付费、原声带与设定集；不卖皮肤、不做体力与广告——保持“纯判定”的品牌一致性

### 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 曲库为空的版权与制作成本 | 无内容可玩 | 优先与独立曲师/同人社团互换授权；先做免费授权曲，付费章节再谈商用 |
| 1:1 复刻舞台“太素” | 第一眼不够吸睛 | 用故事板后处理 shader 与打击特效补氛围，判定画面本身保持零干扰——这是刻意选择 |
| 叙事依赖谱面排序 | 剧情错位 / 剧透 | 章节化文件名（`0_1` / `0_2` / `0_3`）+ 自然序排序规则，掉落按 N 映射，规则写进文档 |
| 单人开发范围失控 | 拖期 | 复用网页制谱器与自动化测试；每章只加一个新系统，其余冻结 |
