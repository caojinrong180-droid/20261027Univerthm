# 剧情放这里

收藏品页的「剧情」分类会把这里的 `.txt` 列出来（列表形式），点标题读全文。
子文件夹也认（最多两层），现在放的是 `序章/`：

```
剧情/
  序章/
    Stra的笔记#1.txt
    Stra的笔记#2.txt
    Stra的笔记#3.txt
```

## 掉落：没搜集到就不显示

文件在这里 ≠ 玩家能看见。剧情是**通关掉落的收藏品**：

- 选曲列表里**第 N 首谱面**通关 → 掉**第 N 篇**剧情（按文件名自然排序，所以是 #1 / #2 / #3）
- 每篇只掉一次；自动演示不掉
- 结算界面最下方会显示「收藏品 · Stra的笔记#1 已搜集」
- 进度存在 `user://collection.cfg`（`[stories] unlocked`，按文件名记）；
  想重新体验一遍掉落就删掉这个文件

## 放法

- 丢进这个目录（`res://剧情/`，随游戏发布），切到「剧情」分类就会重新扫一遍
- 或者直接把 `.txt` **拖进游戏窗口**：自动复制到 `user://剧情`（玩家目录里的剧情目录）
- 在游戏里切到「剧情」分类、或者按 `R`，都会重新扫一遍目录，刚放进去的不用重启
- 改了文件名 = 重新上锁（进度按文件名记），改内容不影响

文件名按自然顺序排（`2` 排在 `10` 前面），标题默认取文件名。

## 写法

纯文本就行，不用写任何标记。想排得好看一点可以用这几条：

```text
标题：雪线之下          ← 第一行写标题（也认「题目：」「title:」）；不写就用文件名
# 第一章 相遇           ← 行首 # 或 【】 或「第X章」都当作小标题
　　正文段落，空行分段。
---
                        ← 三个以上的 - 或 = 画一条分隔线
【第二章 回声】
正文……
```

- **一行一段**：一行以 `。` `！` `？` `…` `"` 之类结尾就自成一段（现在这几篇就是这么分的）；
  一行没写完就接到下一行，所以英文硬折行也不会被拆断
- 列表里会显示摘要、字数、预计阅读时长（350 字 / 分钟）

## 编码

- **UTF-8**（带不带 BOM 都行）最好
- 记事本存的 **UTF-16**（「Unicode」）也能自动读
- **ANSI / GBK** 读不了，会用乱码显示并提示——用记事本「另存为」选 UTF-8 就好

导出版本记得保留 `*.txt`（`export_presets.cfg` 的 `include_filter` 已经带上）。
