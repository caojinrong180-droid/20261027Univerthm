# 剧情放这里

收藏品页的「剧情」分类会把这里的 `.txt` 自动列出来（列表形式），点标题读全文。
子文件夹也认（最多两层），现在放的是 `序章/`：

```
剧情/
  序章/
    Stra的笔记#1.txt
    Stra的笔记#2.txt
    Stra的笔记#3.txt
```

## 放法

- 丢进这个目录（`res://剧情/`，随游戏发布），切到「剧情」分类就会自己出来
- 或者丢进 `user://剧情/`（收藏品页「剧情」分类右边的「＋ 剧情目录」可以直接打开）
- 或者直接把 `.txt` **拖进游戏窗口**：自动复制到 `user://剧情`，列表立刻刷新

文件名按自然顺序排（`2` 排在 `10` 前面），标题默认取文件名。

## 写法

纯文本就行，不用写任何标记。想排得好看一点可以用这几条：

```text
标题：雪线之下          ← 第一行写标题（也认「题目：」「title:」）；不写就用文件名
# 第一章 相遇           ← 行首 # 或 【】 或「第X章」都当作小标题
　　正文段落，空行分段。
---
                        ← 三个以上的 - 或 = 画一条分隔线
【第二章 回声】
正文……
```

- **一行一段**：一行以 `。` `！` `？` `…` `"` 之类结尾就自成一段（现在这几篇就是这么分的）；
  一行没写完就接到下一行，所以英文硬折行也不会被拆断
- 列表里会显示摘要、字数、预计阅读时长（350 字 / 分钟）

## 编码

- **UTF-8**（带不带 BOM 都行）最好
- 记事本存的 **UTF-16**（「Unicode」）也能自动读
- **ANSI / GBK** 读不了，会用乱码显示并提示——用记事本「另存为」选 UTF-8 就好

导出版本记得保留 `*.txt`（`export_presets.cfg` 的 `include_filter` 已经带上）。
